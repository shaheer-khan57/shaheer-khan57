### 🧠 ACTE-Former
**Autocovariance Embedding and Tanh-Similarity Attention for Time Series Forecasting**

Developed a Transformer-based forecasting framework incorporating **Autocovariance Temporal Embedding** and **Tanh-Similarity Attention** for learning temporal dependencies in time-series data.

**IEEE ICET 2026 | Paper ID: 307 | Accepted for presentation**
